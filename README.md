# Takeoff Bridge

## Overview
* **Purpose**: Translation middleware converting multi-quantity wide-row Togal.ai CSV exports into deterministic estimate lines and Procore-ready budget line items.
* **Core Function**: Eliminates manual estimation data entry while protecting target ERP cleanliness using an isolated suffix cost-code mapping system.

## Tech Stack
* **Framework**: Next.js 15+ (App Router)
* **Language**: TypeScript (Strict Mode)
* **Database**: Cloud Firestore
* **Data Grid**: TanStack Table v8 (React Table)
* **Styling**: TailwindCSS + Shadcn/ui
